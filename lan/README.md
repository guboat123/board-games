# เล่นหลายเครื่องในวง WiFi เดียวกัน

โฟลเดอร์นี้เป็น **ของเสริม** เว็บบน GitHub Pages ยังเล่นเครื่องเดียวได้เหมือนเดิมโดยไม่ต้องใช้อะไรในนี้

ที่ต้องมีตัวกลาง เพราะเบราว์เซอร์เปิดพอร์ตรอรับการเชื่อมต่อเองไม่ได้
และหาเครื่องอื่นในวง LAN เองไม่ได้ ดังนั้นถ้าจะเล่นแยกเครื่องจริงๆ ต้องมีคนหนึ่งเป็นเจ้าภาพ

## วิธีเล่น

บนเครื่องเจ้าภาพเครื่องเดียว (โน้ตบุ๊กที่ต่อ WiFi เดียวกับทุกคน)

```bash
node lan/server.mjs
```

จอจะขึ้นไอพีให้ เช่น `http://192.168.1.42:8080`
ทุกคนเปิดลิงก์นั้นในมือถือ แล้วเข้า **เกม 03 โป๊กเกอร์** ใส่ชื่อกับจำนวนชิปที่จะซื้อ
ใส่รหัสห้องให้ตรงกันทุกคน แค่นั้น

- ไม่ต้องลง dependency อะไรเลย ใช้ของที่มากับ Node
- ไม่ออกอินเทอร์เน็ต ไม่มีบัญชี ไม่มีค่าใช้จ่าย
- เปลี่ยนพอร์ตได้ด้วย `PORT=9000 node lan/server.mjs`

## ทำไมตัวกลางต้องถือไพ่เอง

โป๊กเกอร์มีข้อมูลลับ (ไพ่ในมือ) ถ้าปล่อยให้เบราว์เซอร์แจกไพ่กันเอง
ใครเปิด devtools ก็เห็นไพ่คนอื่นหมด ตัวกลางจึงเป็นคนสับไพ่ แจกไพ่
และส่งให้แต่ละเครื่องเห็นเฉพาะไพ่ของตัวเอง

## ไฟล์ในนี้

| ไฟล์ | ทำอะไร |
|---|---|
| `server.mjs` | เสิร์ฟไฟล์ + WebSocket (เขียนเอง ไม่ใช้ไลบรารี) + จัดการห้อง |
| `poker-room.mjs` | โต๊ะหนึ่งโต๊ะ: ที่นั่ง บอด ลำดับเดิมพัน ปุ่มดีลเลอร์ จบมือ |
| `poker-engine.mjs` | ตรรกะไพ่ล้วน: สับไพ่ อ่านชุดไพ่ 7 ใบ แบ่งกอง จ่ายเงิน |

`poker-engine.mjs` ไม่ยุ่งกับเน็ตเวิร์กเลย ทดสอบแยกด้วย node ได้
