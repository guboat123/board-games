# เดาสีจากคำใบ้ — 7 ข้อ

### A1 · คำที่มีสระบน+วรรณยุกต์ ยังล้นทับป้าย "คำใบ้ที่ 1"
`แม่น้ำ` `น้ำแข็ง` ผ่านแล้ว (เหลือ 2.46px) แต่โครงสร้างที่สูงกว่าคือ สระบน+วรรณยุกต์
( ◌ี+◌๊ / ◌ิ+◌๊ / ◌ั+◌๊ ) ยังทับอยู่ — `เกี๊ยว` ทับ 1.86px, `เจี๊ยบ` ทับ 2.40px
จากคำไทย 30 คำที่ทดสอบ **มี 7 คำทับจริง** และอีก 7 คำเหลือช่องว่างไม่ถึง 2px
(`เดี๋ยว` 0.03px, `ก๋วยเตี๋ยว` 0.32px)

**แก้**: `.cluebar .c1` (`index.html:189`) — ใช้แนวเดียวกับที่ทำกับ h1/h2/h3 ใน `assets/style.css`

**ต้องวัดยืนยันด้วยคำที่หนักที่สุดจริงๆ** ไม่ใช่แค่ `แม่น้ำ`

### A2 · กติกา "คำใบ้ 1 คำ" บังคับไม่ได้จริงในภาษาไทย

maxlength ปัจจุบัน 40 (clue1) / 60 (clue2)

**แก้**: เพิ่มเพดานความยาวเป็นตัวช่วยที่สอง นับเฉพาะ**อักษรฐาน** (ตัด combining marks

จะโดนบล็อกผิดๆ
เสนอ: clue1 ≤ 12 อักษรฐาน · clue2 ≤ 22
ตรวจว่าคำยาวที่ถูกต้องยังผ่าน: `ฟ้าทะลายโจร` (10) `ประชาธิปไตย` (10) `ก๋วยเตี๋ยว` (8)

### B2 · แถว A, B, P ทั้งแถวเป็นสีเดียวกันในสายตาคน แต่การ์ดยังสุ่มมาเท่าๆ กับแถวอื่น
วัด ΔE (CIE76) จากสีที่เรนเดอร์จริง 30 ช่องในแต่ละแถว:
- แถว A ต่างกันมากสุดทั้งแถวแค่ **ΔE 16.5** (ช่องข้างกันเฉลี่ย 1.34 — ต่ำกว่าเกณฑ์ 2.3 ที่คนแยกออก)
- แถว B 37.1 · แถว P 45.6 · แถว O 73.3 · เทียบแถว I ตรงกลาง **238.3**
- hue วนครบวง (คอลัมน์ 1 = 0°, คอลัมน์ 30 = 348°) ทำให้หัวกับท้ายกระดานคล้ายกันผิดปกติ:
  ΔE คอลัมน์ 1 vs 30 = 1.55 (แถว A) / 3.13 (B) / 4.17 (P) ทั้งที่ห่างกัน 29 ช่อง = 0 แต้ม

ต้นเหตุ (`cellColor` ที่ :465-470):
```js
var hue = (col - 1) / 30 * 360;              // วนครบวง หัวกับท้ายชนกัน
var lightness = 92 - rowIndex * 5;           // แถว A = 92% เกือบขาว, แถว P = 17%
var saturation = 32 + Math.sin(rowIndex / 15 * Math.PI) * 56;  // แถวหัวและท้าย ตกเหลือ 32%
```
แถว A ได้ L 92% + S 32% = เกือบขาวหมดทุก hue

**แก้**: ให้ saturation ไม่ตกที่ปลายทั้งสอง + แคบช่วง lightness + เลิกวน hue ครบวง เช่น
```js
var hue = (col - 1) / (COLS - 1) * 320;      // 0..320 เหลือช่องว่าง 40° กันหัวชนท้าย
var lightness = 86 - rowIndex * 4.5;         // 86..18.5
var saturation = 55 + Math.sin(rowIndex / 15 * Math.PI) * 35;  // 55..90
```
⚠️ ต้อง**วัด ΔE ยืนยันในเบราว์เซอร์** หลังแก้ ไม่ใช่เดา — เป้าคือทุกแถวมี ΔE สูงสุดข้ามคอลัมน์
เทียบเคียงแถวกลางได้ (อย่างน้อยหลักร้อย ไม่ใช่ 16.5)
ไม่มี state ที่เก็บสีไว้ เปลี่ยนสูตรได้เลยไม่กระทบข้อมูลเก่า

# โป๊กเกอร์ — ไม่มีผล

agent รอบ 4 ถูกหยุดกลางคัน ต้องส่งใหม่ทั้งชุด
บรรทัดสุดท้ายที่รายงานคือชิปยังบาลานซ์ครบภายใต้การทดสอบหนัก แต่ยังไม่ได้สรุปผล

รอบ 3 แก้ไป 8 จุด (สวมสิทธิ์ที่นั่ง, กองกลางรวมเงินที่ยังไม่มีใครตาม, สิทธิ์เจ้าภาพ,
ที่นั่งกระโดดกว้างที่ 430px, ไพ่กลางโดนทับ, ไพ่ในที่นั่งล้นกล่อง, กล่องผลทับกองกลาง,
lobby ไม่ต่อใหม่, ช่องซื้อชิปตอน rejoin) — ผมวัดยืนยันเองแล้วทุกข้อก่อน commit
