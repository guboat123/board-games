# งานถัดไป — ระบบผู้เล่น + กระดานคะแนน

วางข้อความข้างล่างนี้ทั้งก้อนใน Claude Code ที่ root ของ repo

---

อ่าน `CLAUDE.md` ก่อน แล้วทำตามนี้ ห้ามฝ่าฝืนข้อจำกัดในนั้น

## 1. สร้าง `assets/players.js`

โมดูลกลางเก็บทะเบียนผู้เล่นและประวัติการเล่น ประกาศเป็น `window.Players`

เก็บใน localStorage คีย์ `bg.players.v1` และ `bg.history.v1` ห่อ try/catch ทุกจุด ถ้าอ่าน/เขียนไม่ได้ให้ตกลงมาใช้ตัวแปรในหน่วยความจำแทนแล้วเล่นต่อได้ปกติ ห้าม throw ออกมา

API:

- `Players.all()` คืน array ของ `{ id, name, createdAt }` เรียงตามชื่อ
- `Players.add(name)` ตัดช่องว่างหัวท้าย ปฏิเสธชื่อว่างและชื่อซ้ำ (เทียบแบบไม่สนตัวพิมพ์) คืน player object หรือ `null`
- `Players.rename(id, name)`
- `Players.remove(id)` ลบชื่อออก แต่ประวัติเก่าที่บันทึกไว้ให้คงชื่อ ณ ตอนนั้นไว้
- `Players.get(id)`
- `Players.recordGame(record)` โดย record คือ
  ```js
  { game: "catch-sketch", gameLabel: "วาดให้ทาย", playedAt: <timestamp>,
    results: [ { playerId, name, score, won: true|false } ] }
  ```
- `Players.history(limit)` คืนประวัติล่าสุด เรียงใหม่ไปเก่า
- `Players.stats()` คืน array ต่อผู้เล่น `{ id, name, games, wins, points }` เรียงตาม wins แล้ว points
- `Players.clearHistory()`

เก็บประวัติไว้ไม่เกิน 200 รายการล่าสุด เกินกว่านั้นตัดทิ้งอันเก่าสุด

## 2. เพิ่มส่วน "ผู้เล่น" ในหน้า `index.html`

ใต้รายการเกม เพิ่มการ์ดหนึ่งใบ:

- ช่องกรอกชื่อ + ปุ่ม `เพิ่มชื่อ`
- แสดงรายชื่อที่ลงทะเบียนไว้เป็นชิป แต่ละชิปกดแล้วมีปุ่มลบ
- ถ้ายังไม่มีใครเลย แสดงข้อความชวนให้ลงชื่อ ไม่ใช่ช่องว่างเปล่า
- ลิงก์ไป `scoreboard.html`

ใต้ชื่อเกมแต่ละอันในการ์ดเกม ให้แสดงจำนวนคนที่แนะนำให้ชัด: วาดให้ทาย = `แนะนำ 4–12 คน` เดาสีจากคำใบ้ = `แนะนำ 3–10 คน`

## 3. สร้าง `scoreboard.html`

ใช้ `assets/style.css` และ `assets/players.js` หน้าตาแนวเดียวกับหน้าอื่น

- ตารางอันดับ: ชื่อ / เล่นไป / ชนะ / แต้มรวม เรียงจากชนะมากสุด
- อันดับ 1 เน้นด้วย `--ink-orange`
- ด้านล่างเป็นประวัติ 20 เกมล่าสุด: วันที่ ชื่อเกม ใครชนะ แต้มเท่าไหร่
- ปุ่ม `ล้างประวัติทั้งหมด` ต้องกดยืนยันอีกครั้งก่อนลบจริง
- ถ้ายังไม่มีข้อมูล แสดงข้อความบอกว่าต้องเล่นให้จบสักเกมก่อน พร้อมลิงก์กลับไปหน้าเกม

## 4. แก้ `games/catch-sketch/index.html`

โหลด `../../assets/players.js` เพิ่ม แล้วแทรกขั้นตอนใหม่ก่อนหน้าจอตั้งค่าเดิม

**หน้าจอ "ใครเล่นบ้าง"** (หน้าจอแรกของเกม):

- บอกไว้บนสุดว่า `เกมนี้แนะนำ 4–12 คน`
- ให้เลือกจำนวนคนที่จะเล่นรอบนี้ จาก 4 ถึง 12
- แสดงรายชื่อจากทะเบียนให้กดเลือก เลือกได้เท่ากับจำนวนที่ระบุพอดี ถ้าเลือกเกินให้กดไม่ได้พร้อมบอกเหตุผล
- มีช่องเพิ่มชื่อใหม่ตรงนั้นเลย ไม่ต้องกลับไปหน้าแรก
- ปุ่ม `ตั้งค่าเกม` เปิดใช้ได้เมื่อเลือกครบ

**หน้าจอตั้งค่าเดิม** เพิ่มขั้นแบ่งทีม:

- แบ่งตามจำนวนทีมที่เลือกอยู่แล้ว (2–4 ทีม)
- ปุ่ม `สุ่มทีมใหม่` แบ่งแบบสุ่มให้จำนวนคนต่อทีมต่างกันไม่เกิน 1
- แสดงว่าใครอยู่ทีมไหน กดสลับคนระหว่างทีมได้
- ถ้าจำนวนคนน้อยกว่าจำนวนทีม ให้ลดจำนวนทีมลงอัตโนมัติแล้วบอกผู้ใช้

**ตอนจบเกม** เรียก `Players.recordGame()` โดยแต่ละคนได้ `score` เท่ากับแต้มรวมของทีมตัวเอง และ `won: true` ทุกคนในทีมที่ชนะ เพิ่มลิงก์ `ดูกระดานคะแนน` ในหน้าจบเกม

## 5. เช็คก่อนจบ

- เปิด `index.html` แบบ `file://` แล้วเล่นจบหนึ่งเกมได้ ไม่มี error ใน console
- ปิด localStorage (โหมดส่วนตัว) แล้วยังเล่นได้ แค่ไม่จำข้ามครั้ง
- ย่อหน้าต่างเหลือกว้าง 360px แล้วไม่มีอะไรล้น
- อย่าแตะไฟล์ใน `games/catch-sketch/words/`

ทำเสร็จแล้วสรุปสั้นๆ ว่าแก้ไฟล์ไหนไปบ้าง
