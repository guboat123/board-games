# ก๊วนบอร์ดเกม

เว็บรวมบอร์ดเกมเล่นกับเพื่อน เปิดในเบราว์เซอร์มือถือได้เลย ไม่ต้องติดตั้งอะไร ไม่ต้องมีเซิร์ฟเวอร์

**เล่นเลย:** https://guboat123.github.io/board-games/

## เกมในตอนนี้

| เกม | จำนวนคน | อุปกรณ์ | สถานะ |
|---|---|---|---|
| 01 · วาดให้ทาย | 4–12 คน (แบ่ง 2–4 ทีม) | ไวท์บอร์ด + ปากกา | เล่นได้แล้ว |
| 02 · เดาสีจากคำใบ้ | 3–10 คน | จอเดียว | กำลังทำ |

## โครงสร้าง

```
board-games/
├─ index.html                     หน้ารวมเกม
├─ scoreboard.html                กระดานคะแนนรวม
├─ assets/
│  ├─ style.css                   design tokens ที่ทุกเกมใช้ร่วมกัน
│  └─ players.js                  ทะเบียนผู้เล่น + ประวัติการเล่น
└─ games/
   └─ catch-sketch/
      ├─ index.html
      └─ words/
         ├─ general.js            คำทั่วไป
         ├─ characters.js         ตัวละครดัง
         └─ thai.js               คำหมวดไทย
```

## อยากเพิ่มคำ

เปิดไฟล์ใน `games/catch-sketch/words/` แล้วต่อท้ายบรรทัดสุดท้ายของหมวดที่ตรงที่สุด

```js
{ w: "จักรยานยนต์พ่วงข้าง", en: "sidecar", cat: "vehicle", lv: 3 },
```

- `w` คำไทยที่จะขึ้นจอ
- `en` คำอังกฤษ (ไม่บังคับ แต่ช่วยคนวาดที่นึกภาพไม่ออก)
- `cat` หมวด ใช้ชื่อเดิมที่มีอยู่แล้วในไฟล์
- `lv` `1` ง่าย · `2` กลาง · `3` ยาก

**เกณฑ์:** ต้องวาดได้ ถ้าเป็นนามธรรมล้วนอย่าง "ความยุติธรรม" ให้ข้าม

แล้วส่ง Pull Request มาได้เลย

## อยากเพิ่มเกม

สร้างโฟลเดอร์ใน `games/` ทำ `index.html` ที่ลิงก์ `../../assets/style.css` แล้วเพิ่มการ์ดในหน้า `index.html` หลัก

## รันในเครื่อง

เปิด `index.html` ด้วยเบราว์เซอร์ตรงๆ ได้เลย ไม่ต้อง build ไม่ต้องลง dependency
