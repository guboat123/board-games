# ก๊วนบอร์ดเกม

เว็บรวมบอร์ดเกมเล่นกับเพื่อน เปิดในเบราว์เซอร์ได้เลย ไม่ต้องติดตั้งอะไร ไม่ต้องมีเซิร์ฟเวอร์

**เล่นเลย:** https://guboat123.github.io/board-games/

## เกมในตอนนี้

| เกม | จำนวนคน | อุปกรณ์ | สถานะ |
|---|---|---|---|
| 01 · วาดให้ทาย | 3–6 คน | ไวท์บอร์ด + ปากกา **คนละอัน** และเครื่อง 1 เครื่องวางกลางโต๊ะ | เล่นได้แล้ว |
| 02 · เดาสีจากคำใบ้ | 3–10 คน | แท็บเล็ตหรือโน้ตบุ๊ก 1 เครื่อง (แนะนำจอ 10 นิ้วขึ้นไป) | เล่นได้แล้ว |

### 01 · วาดให้ทาย

รอบหนึ่งมีคนทาย 1 คน ที่เหลือเป็นคนวาดทั้งหมด คนทายหันหลัง ระบบสุ่มคำให้คนวาดเห็นพร้อมกัน
แล้วทุกคนรีบวาดคำนั้นบนไวท์บอร์ดตัวเอง ใครวาดเสร็จก่อนก็แตะชื่อตัวเองคว้าคิวก่อน

พอส่งเครื่องกลับให้คนทาย คนทายจะดูรูปของคิวที่ 1 ก่อน ทายถูกก็จบรอบ ทายผิดสิทธิ์ตกไปคิวถัดไป
หัวใจของเกมคือวาดเร็วได้สิทธิ์ก่อน แต่ถ้าเร็วจนอ่านไม่ออกก็เสียสิทธิ์ฟรี

เกมนี้ไม่มีการจับเวลาในกติกา นาฬิกาบนจอเดินหน้าไว้ดูสนุกๆ เท่านั้น

### 02 · เดาสีจากคำใบ้

กระดานสี 30 คอลัมน์ × 16 แถว รวม 480 ช่อง พิกัด A-1 ถึง P-30
คนใบ้เลือกสีลับจากการ์ด 4 ใบ แล้วให้คำใบ้ 1 คำ คนอื่นทายทีละคนโดยวางหมากบนกระดาน
จากนั้นคนใบ้ใบ้เพิ่มได้อีกไม่เกิน 2 คำ แล้วทายรอบสองเรียงย้อนกลับ

เฉลยแล้วคิดแต้มจากระยะห่างจากสีจริง ตรงเป๊ะ 3 แต้ม อยู่ในกรอบ 3×3 ได้ 2 แต้ม วงถัดออกไป 1 แต้ม
คนใบ้ก็ได้แต้มตามจำนวนหมากที่เข้ากรอบ ใบ้ดีเกินไปหรือกว้างเกินไปก็ได้น้อย

## เส้นแบ่งระหว่างโปรแกรมกับของจริง

| ใครทำ | ทำอะไร |
|---|---|
| โปรแกรม | สุ่มคำ · จำลำดับคิว · นับแต้ม · บังคับกติกาคำใบ้ · เก็บสถิติ · บอกว่าถึงตาใคร |
| คน | วาดรูป · ตัดสินว่าทายถูกไหม · กดปุ่มบอกว่าตัวเองวาดเสร็จ |

โปรแกรมไม่รู้ว่าใครวาดเสร็จก่อนจริง มันเชื่อตามที่คนกดปุ่ม
และมันไม่ตัดสินว่าคำตอบถูกหรือผิด คนทายกับคนวาดตกลงกันเอง

## ระบบผู้เล่นกับกระดานคะแนน

ลงชื่อเพื่อนไว้ครั้งเดียวในหน้าแรก แล้วทุกเกมจะเก็บแต้มให้เอง

- `assets/players.js` เป็นโมดูลกลาง (`window.Players`) เก็บทะเบียนชื่อกับประวัติการเล่นไว้ใน localStorage
  คีย์ `bg.players.v1` และ `bg.history.v1` เก็บประวัติล่าสุดไม่เกิน 200 รายการ
- ลบชื่อออกจากทะเบียนได้ แต่ประวัติเก่าจะยังคงชื่อ ณ ตอนที่บันทึกไว้
- `scoreboard.html` แสดงอันดับรวม (เล่นไป / ชนะ / แต้มรวม) กับประวัติ 20 เกมล่าสุด
- ทุกอย่างเก็บในเครื่องของคุณเอง ไม่ได้ส่งไปไหน เปิดคนละเครื่องก็เห็นคนละชุด
- ถ้าเบราว์เซอร์ปิด localStorage (เช่นโหมดส่วนตัว) ยังเล่นได้ปกติ แค่ไม่จำข้ามครั้ง

## อยากเพิ่มคำ

เปิดไฟล์ใน `games/catch-sketch/words/` แล้วต่อท้ายบรรทัดสุดท้ายของหมวดที่ตรงที่สุด

```js
{ w: "จักรยานยนต์พ่วงข้าง", en: "sidecar", cat: "vehicle", lv: 3 },
```

- `w` คำไทยที่จะขึ้นจอ
- `en` คำอังกฤษ (ไม่บังคับ แต่ช่วยคนวาดที่นึกภาพไม่ออก)
- `cat` หมวด ใช้ชื่อเดิมที่มีอยู่แล้วในไฟล์
- `lv` `1` ง่าย · `2` กลาง · `3` ยาก

**เกณฑ์:** ต้องวาดได้ ถ้าเป็นนามธรรมล้วนอย่าง "ความยุติธรรม" ให้ข้าม

แล้วส่ง Pull Request มาได้เลย

## อยากปรับแต้มของเกม 01

ตัวเลขแต้มเป็นกติกาบ้าน ประกาศไว้เป็น constant บนสุดของสคริปต์ใน `games/catch-sketch/index.html`
แก้ที่จุดเดียวได้เลย

```js
var SCORE_DRAWER      = 2;   // คนวาดที่รูปถูกทายถูก
var SCORE_FIRST_BONUS = 1;   // บวกเพิ่มถ้าคนนั้นได้คิวที่ 1
var SCORE_GUESSER     = 2;   // คนทาย ถ้าทายถูกไม่ว่าคิวไหน
```

## อยากเพิ่มเกม

สร้างโฟลเดอร์ใน `games/` ทำ `index.html` ที่ลิงก์ `../../assets/style.css` และ `../../assets/players.js`
แล้วเพิ่มการ์ดในหน้า `index.html` หลัก

## รันในเครื่อง

เปิด `index.html` ด้วยเบราว์เซอร์ตรงๆ ได้เลย ไม่ต้อง build ไม่ต้องลง dependency
